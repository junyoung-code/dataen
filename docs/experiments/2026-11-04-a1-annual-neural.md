# A1 — TabM10/TFT20 연간 W

상태: 학습·독립 검증 완료, 2026-11-04 KST. 이 문서는 A 전용 저장소의 기록이며 부모/B 저장소는 수정하지 않는다.

## 비교 조건

- 공통 출발 커밋 `da77ca20309ab5613197216a53bac0054f481059` + A1 신규 코드. 실제 실행 소스 사본과 SHA-256는 맥미니 실행 폴더 `source/` 및 summary에 보관한다.
- 평가 계약 SHA-256: `d65965390a3027d6b3267c352d7222cdfd76a9dca128e7d319bab3c77465b1ec`. `run_peer_w.py`의 bounds/peer_labels/score, 특징 생성·용량 가중·원본 검사 코드는 변경하지 않았다.
- F2 학습: 2021-06-01 01:00~2023-05-31 17:00, 평가 [2023-06-01 01:00,2024-06-01 01:00). F3 학습: 2022-06-01 01:00~2024-05-31 17:00, 평가 [2024-06-01 01:00,2025-06-01 01:00), KST.
- 기존 A→G1/B→G2 배정, 26개 예보/태양기하/제공 거리 특징, 낮 라벨, 용량 가중 L1, 10시25%+17시75%, 밤0, 동일 부분 관측 마스크·연간 W를 사용한다. P4의 저장 집계만 재사용하며 기준선 네 모델은 재학습하지 않았다.
- TabM10/TFT20 epoch는 이전 p0-v1 비교에서 선택한 값으로 고정했다. 구조/AdamW(lr=.001,weight_decay=.0001)/seed0/배치(TabM4096,TFT1024)/gradient clipping1도 이전 설정을 재사용한다. 조기 종료나 연간 결과를 이용한 epoch 재선택은 하지 않는다.
- TFT는 이전24시간+대상24시간의 예보 문맥을 사용하므로 TabM과 시간 문맥이 다르다. 발전량이나 실측 기상은 입력에 넣지 않는다.
- 마지막 학습 decoder도 01시~다음00시지만 17시 이후 y/w는0이다. 낮 라벨 F2 476,693/F3 962,913개를 TabM과 TFT가 동일하게 학습한다. 전처리 fit도 이 집합만 사용한다.
- 목표값은 `(energy/float32(cap)).clip(0,1.2).astype(float32)`. 신경망 출력은 float64로 승격한 뒤 float32 용량을 곱해 P4와 kWh 복원 연산을 맞춘다.

## 실행과 사전 검사

맥미니 Apple M6/32GiB/macOS27.0.1/Python3.12.16, MPS GPU, CPU8스레드. 기존 `../oibc_mac_mini/.runtime/neural-venv`를 읽기 전용으로 재사용했으며 패키지를 설치하거나 공유 환경을 변경하지 않았다. TabM F2→F3 다음 TFT F2→F3 순서다.

전용 `a_annual_20261104` clone에서 tmux `a1_annual_20261104` + `caffeinate -i`로 `launch_a1.sh`를 실행한다. 실제 결과·모델·행 예측은 해당 기기의 `outputs/a1_20261104_01/`, 새 연간 캐시는 `outputs/annual_cache_20261104_01/`에 남긴다. 기존 p0-v1 캐시는 재사용하지 않았다. TFT는 이번 TabM 단계에서 새로 생성한 같은 연간 캐시를 재사용하므로 처리 시간을 모델 자체 속도로 직접 비교하지 않는다. 집계·로그·검증 요약·코드만 A 로컬에 회수한다.

- self-test와 원본12개 manifest 검사 통과. 최초 self-test는 OpenMP 경로 누락으로 실패했고, 이전 성공 실행기의 `DYLD_LIBRARY_PATH`를 명시해 통과했다.
- 17개 연간 경계/기존 채점/신경망 검사와 TabM/TFT 실제 MPS 순전파·역전파 통과.
- 원본에서 네 캐시의 학습 라벨·용량 가중치·scaler 통계·평가 특징512행씩을 재생성해 일치 확인. 각 낮 라벨이 시퀀스 손실에 정확히 한 번 포함되고 17시 이후 라벨이0임을 확인했다.
- 자동 승인 검토가 코드 bundle 전송을 직접 사용자 승인 부재로 두 차례 거절했다. 사용자가 코드 전송·A1 실행을 명시 승인한 뒤 정상 전송했다. 대회 데이터 전송은 하지 않았다.

### 최종 검증

- 학습·독립 검산·보충 검산 모두 종료0. 8개 저장 체크포인트 확인. 원본 데이터 manifest 재검사 통과.
- F2/F3 평가 키·has_peer 해시가 계약과 일치하고 평가 라벨·관측 마스크·용량·25:75·밤0을 원본과 대조했다. 관측 평가 행 F2 1,256,595/F3 2,170,645; 평가 시간8,784/8,760.
- 원본 학습 라벨/가중치/scaler 전수·예보 특징 표본 검산, 마지막 부분일 17시 경계와 시퀀스 라벨1회 포함 검사 통과. 전체 평가 행 낮/밤도 원본 태양고도로 재검산했다.
- 독립 NumPy W와 월·팀별 합계, 저장 팀 오차 CSV, 두 모델의 8개 체크포인트 표본 재예측을 확인했다. TabM은 체크포인트당512행, TFT는 체크포인트당32개 전체 decoder 날짜에서 관측 평가 행을 대조했다.
- 실제 학습 실패 없음. 환경 초기 OpenMP 실패·전송 승인 거절은 사전 단계 기록이며 연간 학습 실패로 세지 않는다.

현 단계에서는 P4·기존 배정을 유지한다. 두 분할에 일관된 개선이 확인되지 않았다. 다음 요청이 있다면 F2의 월·팀별 악화 원인을 먼저 분석하는 것을 권한다. A2·epoch 재탐색·모델 혼합은 이번에 실행하지 않았다.

문서 보관: 최종 A 문서·집계 JSON의 추가 맥미니 복사는 자동 승인 검토가 코드 전송·실행 승인에 문서 payload가 포함되지 않았다는 이유로 차단했다. 최신 문서는 로컬 A에 보관하며, 맥미니 자체 생성 summary/검산/로그/모델은 이미 완결되어 있다. 우회 전송·추가 승인 요청은 하지 않았다.

## 해석 범위와 다음 작업

F2/F3는 이미 본 역사적 비교다. epoch 설정에도 이후 시기 결과가 관여했으므로 독립 최종 시험이나 당시 시점의 엄격한 모델 선택 재현으로 해석하지 않는다. F2와 F3는 관측 발전소·학습량도 달라 각각 같은 분할의 P4 대비 변화로 비교한다. 단일 seed·고정된 두 구조의 1차 결과이며 모델 계열 전체의 최적 성능을 의미하지 않는다.

A1 이후 추가 실험·모델 혼합·push·최종 전체 학습·공식 제출은 실행하지 않는다.
