# TabM·LSTM·TFT 비교 — 2026-11-03

맥북에서 TabM→LSTM, 맥 미니에서 TFT를 동시에 진행했다. 세 모델 모두 처음부터 학습했고 모든 기간의 실행·독립 검증을 완료했다. 기존 세 트리 모델과 합쳐 비교한다.

**현재 LightGBM 기준은 유지한다.** TabM은 1~2월에 6.13% 개선했지만 3~5월에는 0.48% 악화했다. TFT의 3~5월 차이는 +0.02%로 매우 작아 단일 실행으로 우열을 확정하기 어렵고, 1~2월에는 5.23% 악화했다. 다음 추가 실험은 TabM을 우선 검토하고 TFT도 후보로 보관한다. 두 모델 모두 모든 주요 기간에서 안정적으로 개선한 것은 아니다.

월별로 TabM은 1·2·5월 개선/3·4월 악화, TFT는 1·2·3월 악화/4·5월 개선이었다. LSTM은 1~4월 악화/5월 개선이었다. 따라서 모델 간 혼합의 가능성은 후속 검토 대상이지만 이번에 혼합 효과를 시험하지는 않았다.

## 탐색한 범위

| 모델 | 5 epoch | 10 epoch | 20 epoch | 선택 |
|---|---:|---:|---:|---:|
| tabm | 580.323 | 542.958 | 578.123 | 10 |
| lstm | 664.880 | 676.636 | 693.430 | 5 |
| tft | 638.500 | 647.436 | 608.688 | 20 |

위 값은 tune 팀 점수다. 각 모델의 한 구조를 20회까지 연속 학습하며 5/10/20회 체크포인트를 비교했다. 독립 초기화 3회나 폭넓은 구조 탐색이 아니다. 선택한 횟수는 다른 기간에도 고정했다.

- TabM: 공식 패키지, 수치 임베딩 없음, 3블록·폭128·내부8모델·dropout0.1. 각 내부 모델의 가중 L1을 학습하고 예측을 평균한다.
- LSTM: 인코더/디코더 각1층·폭64. TFT: PyTorch Forecasting 구현, 폭16·연속변수폭8·헤드4·LSTM1층·dropout0.1.
- AdamW 학습률0.001·weight_decay0.0001, gradient clip1, seed0. 배치 크기 TabM4096/LSTM512/TFT1024. MPS float32, CPU 보조 작업8스레드. 수치 정밀도·확률적 학습 특성이 트리와 다르다.
- p0-v1 학습/평가 기간·관측 라벨·낮 학습 행·용량 가중식·기존 그룹·10시/17시 25:75·평가 마스크·팀 지표는 동일하다. 기간·학습 행 수는 [기존 비교](2026-11-03-xgboost.md)를 참조한다.
- 신경망은 학습 구간의 관측된 낮 입력으로 결측 중앙값·평균·표준편차를 맞추고 ±10 표준편차로 자른다. 미래 라벨은 전처리·입력에 넣지 않는다. 밤·실측 결측은 학습 손실에서 제외하고 평가 결측은 0으로 채우지 않는다.
- LSTM/TFT는 이전24시간 예보를 인코딩하고 대상일01시~다음날00시의 예보24개로 예측한다. 26개 변수는 같지만 시간 문맥이 추가되므로 완전히 같은 입력 구성은 아니다. 과거/미래 실제 발전량·실측 기상·ID는 입력에 없다.
- LightGBM의 P1~P4 누적 탐색이 더 많고 공통 입력·손실·혼합도 그 결과를 보고 선택했다. 이번 결과로 모델 계열의 최적 성능 순위를 확정하지 않는다.

| 모델 | 기기 | 전체 실행 초 | 선택 모델 학습 초: tune / 계절 / 확인 | 최대 프로세스 RSS MiB |
|---|---|---:|---|---:|
| tabm | Apple M1 Pro MPS | 749.0 | 175.8 / 101.4 / 200.8 | 3143.7 |
| lstm | Apple M1 Pro MPS | 176.4 | 29.1 / 15.0 / 37.2 | 951.3 |

단일 실행 측정이다. 전체 실행은 설치·사전 GPU 시험·독립 검증을 제외한다. TabM의 tune/10시 입력 캐시는 사전 검사에서 준비했고 LSTM은 맥북 캐시를 재사용했다. 선택 모델 학습 시간은 두 예보 모델의 합계다. RSS는 GPU 전체 메모리 측정값이 아니며 서로 다른 기기 및 CPU 트리 모델과 시간을 직접 비교하지 않는다.
