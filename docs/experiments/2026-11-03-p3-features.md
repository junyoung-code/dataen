## 검증과 한계

- 맥북·맥 미니 단위 테스트 각각 22개 통과. 예보 조인 키·행 순서·17−10 부호·발전량 라벨 변경에 대한 특징 불변성·미래 시각 행 격리·결측·중복·풍속 단위·거리 검사 포함.
- 기준선 재학습의 각 예보 예측이 기존 P1 저장 예측과 일치하고, 혼합 팀 가중 오차가 P2와 일치했다.
- 별도 검사로 8개 실행의 원본 라벨·공통 마스크·25:75 혼합·팀 가중 MAE·낮 NMAE·월별 평균 모델 지표를 재계산해 확인. 모델별 200트리·특징 이름과 저장 후 재로딩 예측 일치, 정상 종료 코드 0 확인.
- 독립 검증의 첫 시도는 CSV의 고정 UTC+09:00 표기와 Parquet의 Asia/Seoul 표기 때문에 마스크 동등성 검사에서 중단됐다. 1,416개 실제 시각이 모두 같음을 확인하고 검증 스크립트에서 시간대를 정규화한 뒤 전체 검사를 통과했다. 학습 코드·예측값은 변경하지 않았다.
- 각 후보의 학습/평가 특징 결측률과 상세 월별·팀별·기존/신규 발전소 지표는 [집계 JSON](2026-11-03-p3-features.json)에 보관한다. 결측값은 LightGBM의 기본 결측 처리에 맡기고 행을 삭제하거나 실측을 0으로 채우지 않았다.
- 추가 특징으로 colsample_bytree의 표본 구성도 바뀐다. 한 번의 seed 0 실행이므로 단일 변수의 인과 효과나 통계적 유의성을 주장하지 않는다.
- 세 묶음 각각의 1차 비교 완료이며 ID·과거 편향·묶음 조합 등 모든 가능한 특징 탐색이 완료된 것은 아니다.
