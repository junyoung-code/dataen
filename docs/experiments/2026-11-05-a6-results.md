# A6 — F2 G2 원인 분석과 개선 확인

2026-11-05 KST. 실제 계산·독립 검산·분포 보충 감사를 완료했다. 기존 A3/A5와 원본/배정/평가 계약은 보존했다.

**선택된 보완은 학습 라벨이 없던 G2 발전소에만 TabM을 제외하는 정책이다.** 그 집합은 P4 62.5% + TFT 37.5%, 나머지는 기존 P4/TabM/TFT 50:20:30을 유지한다. F2 G2의 점수는 P4 대비3.984% 악화에서0.843% 개선으로 바뀌었다. 다만 P4보다 우수하다는 구간 추정은 아직 불확실하며, 최종 학습 예정 구간에는253개소 모두 이력이 있어 이 보완 규칙이 발동하지 않는다.

## 원인: 학습에서 보지 못한 G2 집합과 TabM 편향

- F2의 실제 낮 학습 행은 G1 450,045/G2 26,648, 학습 발전소는 G1 100/G2 6개였다. 전체476,693개 학습 행 중 G2는5.59%다. 반면 F2 G2 낮 평가에는 기존6개소와 학습에 없던69개소가 포함됐다.
- 학습에 없던 G2에서 TabM 평균 편향은 **-9.810kWh**, 용량정규화 편향은 **-3.607%p**다. 기존 G2의 용량정규화 편향은-0.047%p였다. 서로 다른 용량/위치/기상 구성의 집합이므로 이력 부재 자체의 인과효과로 해석하지 않는다.
- 해당 cold G2 낮 행의 **16.051%에서 용량 특징이 표준화 제한값(±10)에 닿았다.** 기존 G2에서는 이 현상이 없었다. 학습 분포 밖 큰 용량 입력이 충분히 구분되지 않는 위험 신호지만, clipping만 바꾼 재학습 실험은 하지 않아 단독 인과 원인으로 확정하지 않는다.
- 보충 감사는 원래 평가행 키로 입력 위치를 독립 계산하고 clipping 비율과 실제 학습 표본 균형을 재확인했다. 발전소ID/좌표/원본행은 보고서에 내보내지 않았다.

## 최종 평가 적용 범위

**2023-06-01 01:00~2025-05-31 17:00의 최종 학습 예정 구간에는253개 발전소 모두 낮 학습 기록이 있다.** 이 자료 구성에서는 cold G2 규칙이 발동하지 않아 최종 예측은 원래50:20:30과 같아진다. 따라서 A6는 역사적 cold-start 위험을 보완하는 근거이며 공식 서버 성능이 추가 개선된 실험이 아니다. 최종 모델은 학습하지 않았다.

`g2_correction.apply_policy`는 검산용 오차 집계 연산이다. 실제 예측에서는 같은 계수를 모델 예측값에 적용하면 수학적으로 동등하다. 평가 발전량이나 실측 기상을 예측 입력으로 넣는 정책이 아니다. 별도 최종 학습/서빙 실행기를 구현·검증했다고 주장하지 않는다.
