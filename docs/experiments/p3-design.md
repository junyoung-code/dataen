# P3 1차 특징 비교 설계

2026-11-03, 결과 확인 전 확정. 기준선 200트리·학습률 0.03·10시 25%/17시 75%, CPU 8스레드와 seed 0 유지. p0-v1 tune만으로 선택하며 계절 진단을 별도로 보고한다. 확인 구간은 평가하지 않는다.

| 후보 | 기존 24개 특징에 추가 | 총 특징 |
|---|---|---:|
| baseline | 없음, P2 기준선 재현 | 24 |
| revision | A 6개/B 9개 예보의 동일 지점·대상 시각 17시−10시 변화량, 변화량 결측 플래그 15개 | 54 |
| provider_gap | 같은 라운드의 B−A 운량·기온·상대습도·풍속 차이와 각각의 결측 플래그 | 32 |
| station_distance | 제공된 wa_dist, wb_dist (m) | 26 |

- 세 묶음은 기준선에 **각각 따로** 추가한다. 승자끼리 조합하거나 그 결과로 추가 탐색하지 않는다.
- 공급사 풍속은 B km/h를 3.6으로 나눠 A m/s와 비교한다. 정의가 다른 강수 변수는 공급사 차이에 넣지 않는다.
- 제공 data/README.md의 예보 설명에 따르면 round=10/17은 대상일 전날 발행돼 최종 예측 시점인 전날 17시에 이용 가능하다. 따라서 이번 ‘10시 모델’도 17시 이후 최종 혼합을 위한 구성 요소다. 10시에 제출 가능한 실시간 예측기로 해석하지 않는다.
- 같은 지점·대상 시각으로 조인하며 행 순서·중복 키를 검사한다. 미래 발행 예보, 대상 시각의 실측 날씨, 과거 발전량 통계는 추가하지 않는다. 누락된 예보를 다른 시각에서 채우지 않는다.
- 거리는 제공 메타데이터만 사용하며 좌표로 원래 위치를 추정하거나 재계산하지 않는다. ID 및 과거 편향 특징은 이번 1차 비교에 포함하지 않고 후속 후보로 남긴다.
- 선택은 tune의 팀 가중 MAE 최솟값. 1e-9kWh 이내 동률이면 특징 수가 적은 후보, 다음으로 위 선언 순서를 우선한다. 모두 악화하면 기준선을 유지한다.
- 월별·팀별·신규 발전소 진단, 특징 결측률, 시간·메모리, 원본 라벨·마스크 및 저장 모델 재로딩 검사를 기록한다.
- 기준선을 다시 학습해 P2 점수와 1e-12 상대 허용오차로 비교한다. 특징 묶음 변경 시 colsample_bytree=0.8로 샘플링되는 특징 구성도 달라질 수 있어 단일 변수의 인과 효과로 단정하지 않는다.

이 설계의 세 묶음 비교를 P3 1차의 완료 범위로 삼는다. 모든 가능한 특징 탐색이 끝났다는 뜻은 아니다.
