## 실패·미실행도 기록

- A1 초기 OpenMP 검색경로 누락은 기존환경 경로전달로 해결. 코드전송 자동검토 거절은 사용자 명시재승인 후 실행.
- SSH 인증 거절은 사용자 터미널 재접속 후 복구했다. 결과회수 후의 연결 만료는 완료된 산출물에 영향을 주지 않으며 GitHub 공유는 로컬에서 수행한다.
- A2~A4 선행01은 NumPy matmul 경고가 있었지만 모든후보유한·독립W 검산통과. 데이터없는 회귀실패 재현 후 동등한3항직접합으로 바꿔 새02에서 같은정책/점수·무경고 검증.01 기록 보존.
- 로컬 Parquet engine 부재는 새 설치 없이 기존 신경망환경으로 전환했다. 원본검사 중 sandbox CPU정보 경고는 처리실패가 아니었다.
- A6 초기 합성대칭검사는0근처1.14e-15 차이에 atol=0을 적용해 실패했다. 명시적1e-12 허용오차로 수정 후 통과. 실제모델/성능을 바꾸지 않았다.
- 용량 clipping 단독 인과효과를 확인하는 재학습, 새 미사용 연도 평가, 최종 전체학습·공식제출·B 실험은 미실행이다.
