# A6 — F2 G2 악화 원인 및 개선 확인

사용자 요청(2026-11-05): F2 G2 악화 원인 분석·개선 가능성 확인, A 단계별 결과 모두 기록 후 GitHub push. 기존 push 금지 지침을 이 요청 범위에서 대체한다. 원본/행 예측/모델은 공개하지 않고 코드·설정·실험 집계만 별도 Codex 브랜치에 push한다. 부모/B/다른 기기 미커밋 변경·main을 덮어쓰지 않는다.

## 출발 근거

A5에서 F2 G2의 이전 관측 있음 집합은 개선3.986%, 없음 집합은악화5.479%. A5 기존 오차 배열을 이용한 탐색적 기여분해에서 전체악화W11,075,409.643은 TabM 방향변화+12,404,545.027/TFT방향변화-1,329,135.384로 나뉘었다. 집합분해는기존관측-632,241.480/없음+11,707,651.123. 이는부호오차·절댓값의상호작용을배분한수학적귀속이며, 학습이력부재의인과효과증명은아니다.

탐색에서 F2/F3의 실제 supervised daylight 학습행이 있는 발전소집합(106/205개)이 기존seen플래그와평가행에서완전히일치함을확인했다. 새정책은평가시작전seen이아니라 **원래학습캐시의17시cutoff내supervised행 존재**로판단한다. 이조건은예측시점에알수있다.

## 새후보(이후추가탐색금지)

G1은기존혼합을유지하고G2만세가지정책을비교한다. 팀배정/원본마스크/라운드25:75/학습모델·epoch는그대로이며새학습은없다.

1. `g2_cold_p4`: 학습라벨이없던G2발전소는P4, 나머지는50:20:30.
2. `g2_no_tabm`: G2전체에서TabM을제외하고기존P4:TFT비율을재정규화해62.5:37.5. G1은기존혼합.
3. `g2_cold_no_tabm`: 학습라벨없는G2발전소에만62.5:37.5(P4:TFT), 나머지는기존혼합.

F2앞6개월[2023-06-01 01:00,2023-12-01 01:00)에서 G2 W가P4이하인후보중전체W최소를선택한다(동점이면위순서). 선택을해시로고정하고F2뒤6개월및F3에적용한다. 앞6개월적격후보가없으면기존혼합유지/개선미확인을기록한다. 기반50:20:30은이미F2전체로고른값이므로이6개월분리자체를독립평가로해석하지않는다.

개선정책지지조건: F2전체와뒤6개월G2 W≤P4, F3전체·G2 W≤P4, F3전체W≤기존혼합×1.0025(0.25%이내비용). F3는선택에쓰지않고조건미달이면보류한다. 모든후보의F2/F3점수는투명하게기록하되선택을뒤집지않는다. 선택정책의7/28일5000회paired bootstrap도독립재생검산한다. 기존A3/A5는보존한다.

학습이력fallback이최종평가발전소에서발동하는지도집계수준에서확인한다. 모두학습이력이있는경우cold정책은실제최종예측을바꾸지않으므로역사적검증위험보완과실제서버점수개선가능성을구분한다.
