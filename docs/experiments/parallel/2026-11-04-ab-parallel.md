# A/B 병렬 실험 인수인계

작성·규정 확인: 2026-11-04 KST. 사용자는 두 채팅을 만들고 A는 맥미니, B는 현재 맥북에서 첫 실험부터 진행하도록 승인했다. 현재 저장소의 미커밋 코드도 공통 출발점에 포함하되 기존 작업 폴더는 보존한다.

## 담당과 작업 분리

- A1: TabM 10 epoch, TFT 20 epoch의 F2/F3 연간 W를 측정한다. 과거 p0-v1 결과에서 정한 설정을 고정한다. 이 설정 선택에는 이후 시기 결과도 관여했으므로 엄격한 당시 시점의 모델 선택 재현이나 독립 최종 테스트라고 부르지 않는다. 이번에는 연간 결과로 epoch를 재선택하지 않는다.
- B1: 기존 P4 LightGBM에 GEFS의 넓은 한국 영역 요약 예보(앙상블 평균·산포)를 추가하고 F2/F3 W를 비교한다. 출처·다운로드·발표 시각·재현성 확인과 작은 구간의 수집 시험부터 수행한다. 처음부터 전 지구 자료를 내려받지 않는다.
- 다음 단계(A2~A4 오류/특징 분석·모델 혼합·조건별 혼합, B2~B3 TabPFN v2·TabICLv2)는 계획으로만 유지한다. 첫 실험을 끝내고 결과·다음 권고를 남긴다.
- 작업 폴더: 이 저장소의 `outputs/ab_20261104/a`와 `outputs/ab_20261104/b`에 별도 Git 저장소·브랜치를 준비한다. A는 로컬 폴더에서 원격 실행을 관리하고 맥미니의 별도 `a_annual_20261104` 폴더에서만 학습한다. B는 맥북의 b 폴더에서만 실행한다.
- 공통 원본·문서·main·다른 lane의 폴더와 환경을 수정하지 않는다. 각 lane은 자기 복사본의 문서와 outputs만 갱신한다. 원본 데이터는 기존 로컬 파일을 링크로 읽는다. 환경 변경은 각 lane의 전용 가상환경에서 한다.
- GitHub push·공식 제출은 이번 범위에 없다. 코드/설정/집계만 공유하며 데이터·행 단위 예측·학습 모델은 외부 서비스로 보내지 않는다.

## 공통 평가 계약

정확한 날짜·점수·키/마스크 해시·소스 해시는 각 작업 폴더의 `AB_EVALUATION_CONTRACT.json`에 고정한다. 원본은 `outputs/ab_20261104/control/`에 보관한다.

- 프로토콜: `peer-annual-w-causal-v1`. `run_peer_w.py`의 `bounds`, `peer_labels`, `score`를 공통으로 사용하며 채점 함수는 변경하지 않는다.
- F2 학습: 2021-06-01 01:00 ~ 2023-05-31 17:00 KST, 양 끝 포함. 평가: [2023-06-01 01:00, 2024-06-01 01:00).
- F3 학습: 2022-06-01 01:00 ~ 2024-05-31 17:00 KST, 양 끝 포함. 평가: [2024-06-01 01:00, 2025-06-01 01:00).
- 주 지표: `W = Σ(팀, 시각) SMP × k × |Σ(관측 발전소)(예측−실측)|`. 낮을수록 좋다. 같은 원본 라벨·용량 변환·부분 관측 마스크·기존 A→G1/B→G2 배정으로 평가한다. p0-v1의 완전 관측 시간 마스크와 혼용하지 않는다.
- 10시/17시 두 예보 모델의 출력은 25:75, 밤은 0, 정규화 목표와 용량 가중은 유지한다. A의 신경망 구조와 B의 추가 입력만 각 실험의 변경점으로 기록한다.
- 검증된 P4 기준값: F2 1,121,486,496.8502982 / F3 2,063,719,840.541735. 유효 원본은 `outputs/peer_w_20261103_163512_rescore/`이다. `_rescore` 없는 폴더의 마스크는 사용하지 않는다. 이미 끝낸 기준선 네 모델을 이유 없이 재학습하지 않는다.
- 두 분할은 이미 본 역사적 비교이며 독립된 최종 시험이 아니다. F2 평가 기간이 F3에서는 과거 학습 자료로 들어가는 것은 정상이다. 각각 별도 모델을 학습한다.
- 전처리·결측 대체·정규화는 각 학습 구간으로만 맞춘다. 예측 대상일 전날 17:00 이후 정보는 입력 금지. TFT 시퀀스에서 마지막 학습일을 하루 끝까지 확장해 17시 이후 라벨을 손실에 넣지 않는다.
- 동일 평가 키/마스크인지 확인한 후 W·월별/팀별 오차·기준선 대비 변화·실행 시간·메모리를 기록한다. 일부 날짜 수집 시험만 끝나면 연간 실험 완료로 표시하지 않는다.

## 외부 소스 규정 — 이전 금지 문구보다 이 공지가 우선

출처: 사용자가 이 대화에 전달한 OIBC 운영팀 김민수의 외부 소스 통합 공지. 확인 2026-11-04 KST. 원문 URL과 게시일은 미제공이며 웹에서 별도 확인한 것으로 표현하지 않는다.

- 자유롭게 공개·상업적 이용 가능·같은 주소에서 다시 받을 수 있는 데이터/코드/가중치 없는 모델/사전학습 모델은 허용된다. 출처·라이선스·다운로드 방법을 기록한다. 일회성 배포·개인 복사본만 남은 자료는 불가하다.
- 날짜마다 D-1 17:00 KST 전에 공개된 값만 사용한다. 초기화 시각과 실제 발표 시각을 구분한다. 이미 발표된 예보라면 대상일 다음 날 값도 입력할 수 있다.
- 평가 기간 전체의 통계로 정규화/그룹화하지 않는다. 평가 기간 실측 기상으로 예보 결측을 채우지 않는다. 시점 이전에 나온 다른 예보는 가능하다.
- 다른 발전소의 평가 기간 발전 실적은 사용 금지. 그 이전 과거 실적은 공개·상업 이용·재다운로드 조건을 충족해야 한다.
- 외부 기상을 발전소 좌표별로 가까운 격자/관측소에 붙이지 않는다. 발전소 좌표 없이 정한 넓은 영역 요약값을 모든 발전소에 동일하게 붙인다. 태양 위치 계산은 허용된다.
- 대회 데이터를 외부 AI 서비스에 올리지 않는다. 로컬 프로그램으로만 데이터 처리·학습·예측을 수행하며 채팅/도구 결과로 원본 행을 노출하지 않는다.
- 공지에 없는 내용은 운영팀 확인 대상으로 남긴다. 사전학습 모델별 공개 시점 조건 등 미확인 사항을 확정하지 않는다.

## 이어서 시작할 곳

두 채팅의 진입 지침은 각 lane의 `LANE_START.md`, 생성 결과는 `outputs/ab_20261104/control/dispatch.json`에 기록한다. A1/B1 실제 실행·검증·실패는 각 lane의 EXPERIMENTS와 outputs에만 기록하고, 부모 채팅은 공통 CONTEXT/EXPERIMENT_PLAN에서 배정 상태를 관리한다.
