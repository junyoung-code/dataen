# 기상청 승인 API 하루치 수집 확인 — 2026-11-08 KST

이 문서는 최초 하루치 표본 검증 당시의 기록입니다. 후속 사용자 요청으로 시작한 Mac mini S927 학습·UM 추가 API/자료 품질 검산·수집의 현재 상태는 [별도 실행 기록](2026-11-08-s927-kma.md)을 봅니다.

## 결정과 결과

사용자 지시로 **CAMS는 팀원 담당**, 우리는 기상청 승인 API의 소량 수집을 담당한다. 팀원에게 메시지를 보내거나 CAMS를 중복 수집하지 않았다. 기존 맥미니 작업도 조작하지 않았다.

**KIM 전구 예보로 2025년 7월 2일 하루의 일사량·전체 운량을 각각 24시간 모두 받았다.** 초기화는 2025-07-01 00UTC, 리드는 +16~+39시간이며, 프로젝트 시간 라벨로 07-02 01:00~07-03 00:00 KST다. API 인증 성공과 과거 예보 제공을 확인한 것이며 학습·성능 개선 실험은 아니다.

표본 영역은 발전소 좌표를 읽지 않고 고른 고정 127~128E, 36~37N 상자다. 13×12=156격자 × 24시간 × 2변수, 총 7,488개 값이며 한반도 전체 수집은 아니다. 공식 변수표의 `dswrsfc`는 지표 하향 단파복사(W/m²), `tcld`는 전체 운량(0~1)이다. 초기화·리드·변수 헤더, 격자 수, 유한값, 결측 표식을 검사했고 48개 응답 모두 통과했다. 일사 범위 −1.13687e-13~943.6, 운량 0~1이며 미세 음수 반올림값은 원본 그대로 보존했다. 수집량은 두 변수 합계 112,872bytes다. 시간 평균·누적 방식 등 학습 입력의 시간 정의는 추가 점검 대상이다.

## 실제로 확인한 과거 범위

전 기간을 대량 다운로드하지 않고 다음 초기화 날짜를 조회했다. 연도별 표본 성공을 그 사이 모든 날짜의 확보로 표현하지 않는다.

| 자료 | 실제 응답 확인 | 실패·제한 |
|---|---|---|
| UM 국지 `l015` 일사 `tdsw` | 2021-07-03, 2022-07-01, 2023-07-03, 2024-07-01, 2025-07-01, 2026-03-01, 모두 00UTC/+24h | 2021-07-01·2023-07-01은 파일명만 반환, GRIB 없음. 2026-05-01은 종료 안내 반환 |
| UM 국지 전체 운량 `tcam` | 2021-07-03, 2023-07-03 및 2024-07-01 하루치 | 표본 외 연속성 미확인 |
| KIM 전구 `KIMG` 일사·전체 운량 | 2025-07-01 하루치, 2026-05-01·2026-11-06 각 +24h | 2024-07-01은 파일 오류. `nwp=NE36`을 넣은 2024-07-01·2025-05-01 요청도 NE57/g576 경로를 조회해 오류. 구형 KIM 전체의 미제공을 뜻하지 않음 |
| KIM 지역 `KIMR` | 2026-11-06 기온 T2, 직달·산란 일사 SWDDIR2/SWDDIF2 +24h | LCDC/MCDC/HCDC는 변수 오류. 전구 `tcld` 성공과 구분 |

UM 하루치도 별도로 요청했다. 2024-07-01 00UTC → 07-02 대상 +16~39h에서 전체 운량은 24/24, 일사는 22/24시간을 확보했다. 일사 +16·17h는 파일명만 반환해 결측으로 남겼다. 야간이라는 이유로 0으로 채우지 않았다. 각 GRIB에는 470,162격자 중 결측 1,975개가 있었고 이를 비트맵으로 제외해 검사했다. 유효 일사 범위 0~1,013.029 W/m², 운량 0~1.000007(압축 반올림)이다. 운량 공식 구형 코드표의 % 표기와 실제 0~1 값은 학습 전 단위 처리에서 주의해야 한다.

UM 일사 GRIB의 discipline/category/number는 **0/4/200**, 전체 운량은 **0/6/213**, 하층 운량은 **0/6/3**으로 공식 코드표와 대조했다. ecCodes는 일부 KMA 로컬 변수의 이름·단위를 unknown으로 표시하므로 코드 번호 검증을 생략하지 않았다.

## 공개시각과 사용 가능성

공식 API 문서의 UM 생산 종료일은 **2026-03-31**이며 실제 종료 이후 요청도 거절됐다. 따라서 2026년 5월까지 필요한 전체 구간을 UM 하나로 이어갈 수 없다. KIM과의 겹치는 기간·모델 변경·단위를 확인해야 한다.

이번 표본은 대상일 전날 00UTC 실행본이며 내부 초기화·리드를 확인했다. **실제 과거 공개시각이 전날 17시 이전이었는지의 독립 근거는 미확인**이다. 초기화 시각만으로 공개시각 검증을 대신하지 않는다. 공식 문서도 보유기간과 실제 API 조회기간이 다를 수 있다고 명시한다.

## 실행·검증·실패 기록

- 코드 버전: 상위 `f492bdc` + 미커밋 `scripts/probe_kma_api.py`와 당시 문서 변경. 정확한 소스·계획·공식 문서 SHA-256은 `outputs/runs/kma_api_probe_20261108/code_provenance.json`에 저장했다.
- 기기: 로컬 맥북. 수집기는 기존 Python 3.13.5 표준 라이브러리, GRIB 검사는 기존 Python 3.12 가상환경 + 격리 ecCodes 2.50.0을 재사용했다. 공식 PDF는 번들 pypdf로 읽었다. 패키지 설치·환경 변경 없음.
- 승인 endpoint: `/api/typ06/url/nwp_vars_down.php`, `/api/typ06/url/nwp_nc_vars_down.php`만 사용. 키는 로컬 `.env`에서 읽어 기상청 HTTPS에만 전달하고 계획·로그에 남기지 않았다. 대회 원본은 읽거나 수정·전송하지 않았다.
- 전체 요청은 초기 오류 포함 129건. 유효 검산 대상 127응답 중 **113 데이터 확인 / 10 API 오류·자료 없음 / 4 파일명만 반환**. 유효 데이터 파일은 중복 표본을 포함하며 총 51,841,307bytes다. 각 요청 시간은 JSON에 저장했다. 전체 벽시계 시간·최대 메모리는 별도 측정하지 않았다.
- 초기 UM 응답은 파일명 뒤에 GRIB가 붙어 있었다. 첫 저장기가 이를 텍스트로 잘못 처리한 사본은 `initial_invalid_binary_decode/`에 격리·검증 제외했다. 접두부 판별 실패를 재현한 뒤 수정했고 동일 검사 통과 및 원본 재다운로드를 확인했다. 초기 KIM 기온 요청 HTTP 504도 보존했으며 명시적 재조회는 성공했다.
- 독립 검산은 원본 해시·GRIB 길이/종료표식·날짜·리드·변수코드·격자 비트맵·텍스트 격자 수·값 범위를 확인했다. 검산기 종료 0, KIM 하루치 각 24시간 확인. 새 수집기 회귀검사와 문서 diff 검사도 수행했다. 모델 학습·W 산출·공식 제출은 **미실행**이다.

결과: `outputs/runs/kma_api_probe_20261108/`의 `summary.json`, `verification.json`, `kim_day_summary.csv`, 요청 계획·개별 응답. 파일명에 authKey는 없으며 데이터·원본 응답은 Git 제외다.

## 다음 기기에서 이어갈 일

하루치 재수집·계정 재신청은 필요 없다. 전체 수집을 진행하려면 (1) 학습·평가 구간 연속 가용일 감사, (2) UM/KIM 겹침과 모델 변경·운량 단위·일사 시간 정의, (3) 과거 공개시각 근거를 먼저 확인한다. 빈 응답을 0으로 바꾸지 않는다. 현재 ICON/ENS/TIGGE 자동 실행은 유지하고 CAMS는 팀원 결과를 참고한다. 이번 사용자 요청은 소량 검증까지이며 새 전체 수집·학습을 시작하지 않았다.
