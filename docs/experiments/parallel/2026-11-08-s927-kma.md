## UM 값 검산과 점수 전 설계 수정

고정 9지점은 발전소 좌표를 읽지 않고 미리 선택한 **34/36/38N × 125/127/129E**다. 기존 1.5km GRIB 격자에서 대응 X/Y를 정했고 최대 거리 0.927km였다. 모든 발전소에 동일한 기상 입력을 제공한다.

처음 하루 +16~39h의 48개 일사/운량 값이 돌아왔고, +24h 중심 값은 원본과 일치했다. 그러나 더 넓은 독립 검산에서 **야간 원본은 0인데 지점 API는 20~40대 값을 반환**하는 경우를 발견했다. 370개 대조 중 38개 불일치가 있었고 모두 원본 일사 GRIB의 `bitsPerValue=0`인 상수 0 필드였다. 시간·변수 코드는 원본에서도 확인했다. 기상청 내부 구현의 원인까지 확정한 것은 아니다. 잘못된 값이 원본에도 있다고 해석하지 않았다.

또한 24시간 요청에서 서버가 정확히 약 30초 후 종료하면서 일부 리드를 빠뜨리는 현상을 확인했다. 첫 9지점의 반환 행 수는 32/32/36/48/48/48/48/48/48이었고 전체 99.4425초였다. 성공 HTTP 상태만으로 완전 수집을 선언하지 않는다.

**성능 점수를 하나도 보기 전에**, 첫 UM 비교의 새 입력을 **09~17시 KST(+24~32h)**로 제한했다. 이 시간대 9지점 × 9시간 × 2변수 **162개를 원본 GRIB와 모두 대조 통과**했다. 최대 차이 일사 0.0004626694 W/m², 운량 0.00000495782로 텍스트 반올림 범위다. 9지점 하루 소량 수집은 17.5188초였다. 다른 시간대는 UM 특징을 NaN으로 남기며 임의의 0을 만들지 않는다. 기존 예보/GFS 입력은 그 시간에도 사용한다. 이 결과를 UM 24시간 전체 입력 비교라고 부르지 않는다.

자료 품질에 따른 변경 사유·원본 대조 파일은 `frozen_contract.json`의 pre_score_quality_amendment에 기록했다. 변경 전 계약도 Mac mini `frozen_contract_before_core_quality.json`로 보존했다. 기존 S927 모델 학습 설정은 바꾸지 않았다.

UM 전체 계획은 대상일 2021-01-19~2025-05-31의 **1,594일 × 9지점 = 14,346요청**이며, 변수 2개를 같은 요청에 넣는다. 로컬 맥북에서 수집 중이다. 일일 장부에는 앞선 표본을 고려한 여유 256요청/100MiB를 먼저 잡고, **19,000요청·4GiB**에서 멈춘다. 403/429는 중단하며 키 변경이나 제한 우회는 하지 않는다.

현재 일부 09~17시 응답도 30초 후 시간 누락이 있어, 이미 완전한 응답은 재사용하고 **해당 지점의 부분응답만 최대 한 번** 보완한다. 두 원본 응답을 보존하고 겹치는 값의 일치를 확인한다. 더 많은 시간을 확보한 응답을 선택하고 남은 결측은 그대로 둔다. 수집 완료와 특징 감사 통과는 별도다.

## 실행 환경과 검증

Mac mini 32GiB, 기존 Python 3.12.16 가상환경을 재사용했다. NumPy 2.2.6, pandas 2.2.3, LightGBM 4.6.0, XGBoost 3.4.1, PyTorch 2.15.0. 기존 weather_deps와 새 실험의 vendor를 분리해 사용하며 holidays 0.107, pvlib 0.16.1, h5py 3.16을 새 vendor에만 설치했다. 기존 가상환경을 재설치하지 않았다.

신경망은 기존 architecture/하이퍼파라미터/시드를 유지하고 고립 소스의 fit_mlp 장치 선택에 MPS를 추가했다. 원본 fcst_nn.py를 보존했다. 실제 MPS 학습과 유한 예측 512개를 확인했고, 본 학습 N502c F2 20시드도 완료됐다. 정확한 GPU 수치와 팀원 서버 재현의 차이는 구분한다.

Mac mini self-test 종료 0(CPU 학습·저장·재로딩), check-only 종료 0(12파일·253개소·8,760시간). 신규 실행기 문법 검사와 F114 해시·17시 종료 검사는 통과했다. UM 응답의 UTC 초기화·중복·센티널·누락·완전 종료 표식 검사 6개도 통과했다(0.007초). 새 S927 조립·원본 라벨 최종 검산과 UM 특징의 전체 기간 검증은 아직 실행 전이다.

실패/한계도 보존한다: 첫 원격 tar 해제에서 시스템 Python 3.9의 filter 미지원 → 3.12로 성공; self-test 첫 경로는 src가 아닌 원격 flat 구조라 실패 → 실제 train_smoke.py로 성공; 첫 신경망은 OpenMP 경로를 Python 시작 뒤 지정해 실패 → 시작 전 env로 재실행해 본 학습 진행. 실패 상태 `runs/neural_startup_failed_openmp.json` 및 로그를 보존했다. UM 재조회 추가 뒤 문법 검사에서 들여쓰기 오류 1줄을 발견해 실행 전에 수정·재검사했고, 같은 파일/한도 장부로 재개했다. 문서 링크 검사는 이 상세 보고서 작성 전 누락 링크를 지적했으며 작성 후 다시 확인한다. 최대 메모리·전체 완료 벽시계·새 W는 미측정이다.
