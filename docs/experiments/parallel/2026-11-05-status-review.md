## 팀원 원본 저장소의 추가 진행

사용자가 처음 준 junyoung-code/oibc2026은 aiswody/oibc2026의 fork다. fork main은 기존 93bc88d(11/4 15:19:30 KST) 그대로지만, 원본 main은 a8be440(11/4 23:30:50 KST)까지 추가 기록이 있다. GitHub 연결 도구에서 원본은 404였고 현재 인증된 gh의 읽기 API로 원본과 실험 브랜치를 확인했다. 저장소 동기화나 fork 변경은 하지 않았다.

- S912 실제 제출 S=6,458,641,955, 11/4 15:22 기록 순위57. 현재 실시간 순위를 확인한 것은 아니다. S907a 대비 S +6,793,967. 별도 S908 진단 제출 S=6,454,095,398. 제출 기록4/20.
- 진단상 서버 개선 폭은 로컬의 약 절반(모델 개선0.41배, GFS/혼합0.52배)이었다. 이는 이번 제출들에서 얻은 관찰·계획용 가정이며 모든 후속 실험의 보장 비율이 아니다.
- G309: 그룹 합계를 직접 맞추는 모델에 GFS를 추가해 S913 파일을 생성·검사·보관했다. S912 대비 F2/F3 약0.97%씩 개선, 아직 제출 후보.
- G310: 같은 그룹 직접 모델에 GEFS 평균/산포10열을 추가해 채택. S913 대비 F2 1.06%, F3 0.70% 개선.
- X616: GFS+GEFS 그룹 직접 모델을 합친 S914 방식은 S912 대비 F2 2.02%, F3 1.66% 개선. W=911,692,046 / 1,731,426,894. 이는 로컬 실험값이다. S914 최종 파일 빌드는11/4 23:28 사용자 지시로 중단, 남은 산출물 없음이며 다음 작업으로 기록돼 있다.
- W404: 외부 예보 자료표 완성. 발전소 모델에 입력을 늘린 효과는 기존 조합에 합치면 줄어 X614는 기각. 잎/최소표본·학습률·시드 평균 등 추가 튜닝도 채택 이득 없음.
