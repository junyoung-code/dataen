- 모든 발전소 실측이 있으면 어떤 유효한 팀 배정도 평가 범위가 같다. 결측 실측은 0으로 채우지 않는다. 후보의 예측이 누락·중복·비유한이면 해당 후보 평가를 실패시키고, 후보에 맞춰 평가 행을 줄이지 않는다.

- 주 지표 범위는 겨울·봄에 한정되고 신규 발전소가 없다. 보조 진단의 학습 이력 없는 발전소 29개를 별도로 보고한다. 연중·신규 발전소 성능을 주 지표만으로 일반화하지 않는다.

## 지표

시각 t의 가중치 `w(t) = SMP(t) × k(t)`, KST의 `ts.hour`가 11~15이면 k=3, 그 외 k=1.

**주 지표(낮을수록 좋음)**

```
weighted_group_MAE = Σ[g,t] w(t) × |팀예측(g,t) - 팀실측(g,t)| / Σ[g,t] w(t)
```

- 단위: kWh. 먼저 발전소 예측과 원본 실측을 팀별로 합산한 뒤 절대오차를 계산한다. 발전소별 절대오차를 더하는 것과 다르다.
- 두 팀에서 동일한 SMP를 쓰며 0원 시각의 가중치는 0이다. 총 가중치가 0이면 점수를 계산하지 않는다.
- 제공 정산식의 오차 패널티는 `0.10 × 분자`이다. 동일 시각·전체 발전소를 평가하면 총 실측 수익과 분모가 고정되므로 이 지표를 최소화하는 것이 해당 표본의 정산 대용치를 최대화하는 것과 같다. 공식 리더보드 점수라고 부르지 않는다.
- 보조: 팀 MAE/RMSE/WAPE/편향, 낮 시간 발전소 용량 정규화 MAE, 월별·팀별·학습 이력 유무별 결과, 학습 시간과 최대 메모리. 밤 포함 지표만으로 개선을 판단하지 않는다.
- 학습 타깃의 기존 [0,1.2] 제한은 유지할 수 있지만 평가 실측은 원본 그대로다.

## 정보 시점과 모델 선택

- 제공된 10시·17시 예보와 메타데이터·시간/태양 위치를 이용한다. 같은 시각의 실측 기상·실제 발전량은 예측 입력에 넣지 않는다.
- 과거 통계·특징 인코딩·보정은 해당 학습 구간 안에서만 추정한다. 정보 수신 지연이 불명확한 실측 기반 새 특징은 별도 확인 전 사용하지 않는다. 관측 여부 마스크는 평가에만 쓰고 모델 입력으로 쓰지 않는다.
- P1은 6개 사전 지정 설정을 비교한다. P2는 지정된 3개 혼합 비율을 비교한다. 주 지표 최솟값을 선택하고, 수치 차이가 1e-9kWh 이내면 트리가 적은 설정, 이후 학습률이 큰 설정 순으로 선택한다. 혼합 비율 동률이면 17시 비중이 큰 후보를 선택한다.
- 월별/팀별 악화와 계절 진단을 함께 보고한다. 보조 결과를 보고 선택을 변경하면 그 근거를 튜닝 결정으로 기록한다. 작은 차이를 통계적으로 유의한 개선이라고 단정하지 않는다.
- 확인 기간은 각 실험 단계마다 들여다보지 않는다. P1~P5 중 진행하기로 한 범위의 후보 선택을 마친 뒤 최종 후보와 동일 조건의 기준선을 한 번 비교한다. P1만 수행하는 요청이면 튜닝 결과까지 남기고 확인은 보류할 수 있다.
- 확인 결과를 본 뒤 다시 튜닝하면 이후 수치를 반복 활용한 역사적 검증으로 표시한다. 조기 종료가 필요하면 학습 구간 안에 별도 시간순 구간을 만들고 p0-v2로 문서화한다. 현재 P1은 고정 트리 수 비교다.

## 재현과 검사

프로젝트 가상환경에서, 아직 존재하지 않는 출력 폴더를 지정한다.

```bash
.venv/bin/python validation_protocol.py --output-dir outputs/protocol_p0_v1_new
.venv/bin/python -m unittest discover -v
```

`validation_protocol.py`의 `WINDOWS`, `split`, `complete_hours`, `weighted_group_mae`를 다음 실험 실행기에서 재사용한다. P0 검사기는 모델을 학습하지 않는다. `evaluate_temporal.py`는 이전 1년 검증 재현용으로 유지했다.

2026-11-03 맥북에서 기존 임시 Python 3.12.13 환경으로 실행했다. 기존 OpenMP 라이브러리 위치를 해당 테스트 프로세스에 지정해 기존 검사 5개 + 새 검사 6개, 총 11개 통과. 기존 임시 환경의 기본 라이브러리 검색 경로로는 LightGBM import가 실패했으며 경로 지정 후 통과했다. 맥 미니는 SSH 재인증이 필요해 이번 검사를 실행하지 않았다.

실제 Parquet 시각 정밀도(ms)와 생성 시각 정밀도(ns)의 차이로 초기 마스크 동등성 검사가 실패했다. 시각 값은 같음을 확인하고 마스크를 ns로 정규화했으며 회귀 검사 추가 후 원본 검사까지 통과했다. 초기 실패 폴더는 최종 결과로 사용하지 않는다.

- 최종 로컬 결과: `outputs/protocol_p0_v1_20261103_verified/`.
- 공개 저장: 설정·집계·해시·테스트만. 원본·마스크 행·예측·인증정보는 제외한다.
- P0 완료 당시 다음 작업은 P1 설정 비교였다. 현재 P1~P5와 배정 고정 후 확인까지 완료했으며 최신 시작 지점은 저장소 EXPERIMENT_PLAN.md를 따른다.
