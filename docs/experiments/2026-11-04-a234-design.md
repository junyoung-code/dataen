# A2~A4 사전 실행 설계

사용자 요청: 2026-11-04 “A도 끝까지 이어서 진행해줘”. A1 이후 자동 중단 지침을 이 요청 범위에서 대체한다. A2 오류/특징 진단, A3 고정 혼합, A4 조건별 혼합까지 구현·실행·독립 검산한다. 원본·부모·B 폴더는 읽기 전용, GitHub push·공식 제출은 범위 밖이다.

## 재사용과 공통 평가

A1 TabM10/TFT20의 기존 8개 모델·행 예측, 검증된 P4 연간 집계를 재사용한다. 재학습·추가 epoch 탐색·새 특징 학습은 하지 않는다. 26특징/분할/기존 그룹/부분 관측 마스크/10:17시 25:75/W는 공통 계약 그대로다. 두 모델의 내부 라운드 혼합과 세 모델 사이의 혼합을 구분한다.

P4 행 예측은 기존 맥북에 유지한다. 기존 P4 `group_errors.csv`의 팀×시간 합산 오차만 JSON으로 내보내 A 전용 분석 입력으로 사용한다. 원본행·발전소별 예측·모델·좌표는 기기 간 전송하지 않는다. 같은 마스크에서 팀 합산 오차는 예측의 선형 혼합과 같은 방식으로 섞인다. 조건은 모든 발전소에 동일한 시각별 조건을 적용하므로 이 등식이 성립한다. 입력 키/관측수/가중치·원본 마스크 해시·기준 W를 대조하고 집계 혼합의 수학적 동등성을 별도 검사한다.

## A2 진단

연간·월·시간대·팀·예보 운량·예보 누락률별 W, 부호 있는 팀 오차의 상관/상쇄율을 기록한다. 신경망의 낮 발전소 MAE·편향을 신규/기존 및 정적 용량 구분으로 요약한다. 개별 발전소 오차와 팀 W는 다른 진단이며 특징의 인과적 기여도로 해석하지 않는다. 원본행은 로그로 출력하지 않는다.

## A3 고정 혼합

모델 순서 P4/TabM10/TFT20, 비음수·합1, 0.05 간격의 simplex 231개를 F2 전체에서 비교한다. 동점이면 신경망 비중이 작은 단순 후보를 우선한다. F2 최선의 가중치를 고정해 F3에 그대로 적용한다. F3 결과를 보고 재선택하지 않는다.

## A4 조건별 혼합

조건은 11~15시 peak 여부, 17시 WA 예보의 전체 발전소 설비용량 가중 평균 운량50% 이상 여부(고정 물리 단위), 두 조건 조합이다. 운량은 기존 제공 예보만 사용하며 발전량·실측 기상·평가기간 통계 정규화는 사용하지 않는다. 예보가 전부 결측이면 전역 혼합으로 대체한다. 원본에 있는 발전소-관측지점 매핑을 유지하고 외부 데이터를 추가하지 않는다.

F2 앞6개월 [2023-06-01 01:00,2023-12-01 01:00)에서 조건별 비율을 맞추고 뒤6개월 [2023-12-01 01:00,2024-06-01 01:00)에서 global/peak/cloud/peak_cloud를 비교한다. bin당 유효 팀·시간200개 미만이면 전역 비율로 대체한다. 조건별 후보가 이 확인 구간에서 전역 혼합보다0.25% 이상 개선해야 채택한다. 동점이면 bin 수가 작은 규칙을 우선한다. 선택 규칙만 F2 전체로 다시 맞춘 뒤 selection.json을 해시로 고정하고 F3에 적용한다. 미채택이어도 최선 조건 후보의 F3 결과는 사전에 고정한 진단으로 따로 기록하며 채택을 뒤집지 않는다.
