# P4 목적함수·가중치 비교 설계

2026-11-03 KST, 결과 확인 전 확정. 거리 포함 26특징·200트리·학습률 0.03·10시 25%/17시 75%·seed 0·CPU 8스레드를 고정한다. p0-v1 tune에서 선택하고 계절 진단은 별도로 보고한다. 확인 구간은 평가하지 않는다.

| 후보 | 목적함수 | 정규화 전 학습 가중치 |
|---|---|---|
| l2_uniform | regression (제곱오차, 기존 방식) | 모두 1 |
| l1_uniform | regression_l1 (절대오차) | 모두 1 |
| l1_capacity | regression_l1 | 설비용량 |
| l1_capacity_peak | regression_l1 | 설비용량 × k |
| l1_capacity_peak_smp | regression_l1 | 설비용량 × k × 학습 시각 SMP |

- 위 순서의 인접 후보는 한 가지 요소만 바꾼다. 목적함수 효과, 용량 환산, 시간대 가중, 가격 가중의 효과를 구분한다. 모든 조합을 탐색하는 실험은 아니다.
- 기존 타깃은 발전량/용량이다. 절대오차에 용량을 곱하면 발전소별 kWh 절대오차에 대응한다. 기존 [0,1.2] 타깃 제한은 유지하므로 엄밀히는 제한된 학습 타깃의 kWh 손실이며 평가 실측은 원본 그대로다.
- k는 P0와 같은 KST `ts.hour` 11~15에 3, 나머지 1. 우측닫힘 시간축에 대해 평가식과 동일하게 적용한다.
- sample_weight는 해당 학습 구간의 낮 행에서만 계산하고 그 평균으로 나눠 평균 1로 만든다. 이를 통해 전체 가중치 크기가 변해 정규화·분할 제약에 미치는 영향을 줄인다. 0원 시각은 0 가중치, 행 자체는 제거하지 않는다.
- SMP는 `data/train/smp.csv`에서 해당 학습 시작 이상·끝 미만만 잘라 사용한다. 튜닝·확인 시각의 가격이나 실측을 학습 가중치 계산·정규화에 사용하지 않는다. 과거 실현 가격은 손실 가중치일 뿐 예측 입력이 아니며 미래 가격의 사전 입수를 전제하지 않는다.
- 누락·중복·음수·비유한 학습 가격, 0 이하 전체 가중치, 잘못된 용량은 실패 처리한다. 임의 보간·0 채움은 하지 않는다.
- 발전소별 가중 절대오차 최소화는 팀 합산 절대오차를 직접 최소화하는 것과 다르다. 채택은 같은 공통 평가 시각의 **팀 가중 MAE**로 판단하며 발전소 지표 개선만으로 선택하지 않는다.
- tune 주 지표 최솟값 선택. 1e-9kWh 이내 동률이면 위 선언 순서로, 기존 기준선을 먼저 선택한다. 모두 악화하면 기존 방식을 유지한다.
- 기준선을 재학습해 P3 거리 후보 점수와 1e-12 상대 허용오차로 비교한다. 모델·예측·마스크·학습 가중치 집계·시간·메모리와 월별/팀별/신규 발전소 결과를 남긴다.
- 가중치 변경에 맞춘 트리 수·학습률 재튜닝, L2의 가중치 조합, 혼합 비율 재탐색은 이번 범위 밖이다. 결과를 목적함수 일반의 우열로 확대하지 않는다.
