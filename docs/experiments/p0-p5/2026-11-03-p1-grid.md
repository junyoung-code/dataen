## 실행과 비교 조건

- Python 3.12.16, LightGBM 4.6.0, NumPy 2.2.6, pandas 2.2.3. 제공 데이터 12개 manifest 검사 통과.
- 6설정 × 2개 시간 분할 × 10시·17시 모델 = 24개 모델. 전체 실행 212.464초(약 3분 32초), 개별 worker 최대 메모리 3928.5MiB. 전체 Mac 사용량과는 다르다.
