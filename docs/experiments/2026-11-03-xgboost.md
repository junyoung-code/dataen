# XGBoost·LightGBM·CatBoost 비교 — 2026-11-03

**현재 P4 LightGBM과 기존 참조 배정을 유지한다.** XGBoost 세 설정 중 `xgb_d6_n400`을 1~2월에서 선택했다. LightGBM 대비 팀 가중 MAE 변화는 tune +1.38%, 계절 -6.88%, 3~5월 +2.97%다. `+`는 악화다.

## 같은 조건의 범위

| 항목 | 이번 비교 |
|---|---|
| 원본 데이터·학습/평가 기간·공통 관측 시각 | 동일 |
| 입력 26개·정규화 발전량·낮 학습·야간0 | 동일 |
| 용량 가중(학습 행 평균1)·예보10:17 혼합25:75·기존 팀 배정 | 동일 |
| 평가 지표·실행 기기·요청 CPU스레드 | 동일 |
| 누적 튜닝 횟수·기회 | 다름 |
| 트리 구조·잎 갱신 방식·설정당 연산량 | 모델별로 다름 |

LightGBM은 P1의 트리/학습률6개, P2의 혼합3개, P3의 특징묶음4개, P4의 손실/가중치5개를 단계적으로 비교했다. CatBoost는 이전 세 설정, XGBoost는 이번 세 설정만 탐색했다. 이 숫자는 서로 다른 단계의 후보 수이며 같은 조건의 전체 조합 탐색을 뜻하지 않는다.

공통 입력·손실·혼합 자체도 LightGBM 결과를 보고 선택했다. 따라서 **현 파이프라인에서 모델을 교체하는 효과**를 비교한 결과다. 동등한 탐색 예산을 주어 얻은 모델 계열의 최적 성능 순위로 해석하지 않는다. 같은 트리 수·깊이도 동일한 모델 복잡도나 연산량을 보장하지 않는다.
