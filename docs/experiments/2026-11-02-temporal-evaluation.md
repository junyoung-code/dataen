## 해석 범위와 검증

- 발전소 관측 범위는 전체 격자의 97.94%입니다. 누락 실측은 0으로 채우지 않았습니다. 팀별 주요 수치는 완전 관측 부분집합이므로 선택 편향이 있을 수 있습니다.
- 205개 발전소는 학습 이력이 있고, 48개는 학습 기간에 관측이 없습니다. 평균 모델의 낮 시간 MAE는 기존 발전소 12.466kWh, 신규 발전소 15.461kWh, 정규화 MAE는 각각 7.788%, 8.345%입니다.
- 과거 1년으로 학습한 고정 50트리 모델의 이후 1년 성능입니다. 전체 2년으로 학습한 이전 모델이나 공식 600트리 모델, 비공개 대회 기간의 성능을 직접 뜻하지 않습니다.
- MAE = 평균 절대오차, RMSE = 제곱평균오차의 제곱근, 용량 정규화 MAE = mean(|오차|/설비용량)×100, WAPE = sum(|오차|)/sum(|실측|)×100. WAPE는 정확도 백분율이 아닙니다.
- 시간 경계·원본 라벨·모델 트리 수·야간 0·팀별 완전 관측·지표 및 패널티 재계산 확인. 5개 단위 테스트 통과. 별도 코드 검토에서 수정이 필요한 오류 없음.
- 실행 기록의 Arrow CPU 정보 조회 경고는 샌드박스의 sysctl 제한입니다. 실행은 정상 종료했고 결과 검증도 통과했습니다.

## 파일

- `summary.json`: 전체 지표, 설정, 시간 분할, 데이터 범위.
- `monthly_metrics.csv`: 월별 모델별 지표.
- `site_predictions.parquet`: 관측된 발전소·시간의 원본 실측값과 모델별 예측.
- `group_predictions.csv`: 관측 발전소 합계 예측과 완전 관측 여부. `complete=false` 행은 전체 팀 예측으로 해석하면 안 됩니다.
- `model_round_10.txt`, `model_round_17.txt`: 검증용으로 새로 학습한 모델.
- `verification.json`: 독립 재계산 검증 기록.
