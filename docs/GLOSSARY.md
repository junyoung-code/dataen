# 용어와 번호 읽는 법

**모델 이름, 실험 번호, 평가 기간이 섞여 있습니다. 전부 서로 다른 모델이라는 뜻은 아닙니다.** 번호는 기록을 찾기 위한 이름이며, 숫자가 크다고 성능이 좋은 것은 아닙니다.

## 자주 나오는 표기

| 표기 | 무엇인가요? | 쉽게 읽으면 |
|---|---|---|
| LightGBM·CatBoost·XGBoost·TabM·LSTM·TFT | 실제 모델 종류 | 예측을 배우는 서로 다른 방법 |
| P0~P5 | 우리 초기 실험 단계 | 평가 방법부터 학습 설정·입력·팀 배정을 차례로 비교한 기록 |
| A1~A6 / B1~B3 | 우리 두 작업 묶음의 실험 번호 | A는 맥미니의 신경망·혼합 비교, B는 맥북의 기상 추가·다른 모델 비교 |
| BL1 / BL2 | 우리 혼합 실험 이름 | BL1은 우리 예측끼리 혼합, BL2는 팀원 방식 재현 후 우리 예측 추가 |
| F2 / F3 | **과거 평가 기간** | F2: 2023년 6월~2024년 5월, F3: 2024년 6월~2025년 5월 |
| G314 / G315 | 팀원의 팀 합계 예측 실험 후보 번호 | G315는 G314에 GEFS 31개 예보의 분포 정보 11열을 추가한 후보 |
| S912 / S914 / S915 | 팀원의 제출 후보·결과물 식별 번호 | 모델·혼합·팀 배정을 묶어 제출 파일로 만든 버전. 번호가 있다고 제출 완료인 것은 아님 |
| G1 / G2 | 발전소를 나눈 **두 팀** | G315 실험 번호와 다른 의미 |

P0=평가 기준, P1=트리 수·학습률, P2=10시/17시 예측 혼합, P3=입력 특징, P4=오차 계산 방식·학습 가중치, P5=발전소 팀 배정입니다. **“P4 모델”은 P4에서 선택한 설정의 LightGBM을 줄여 부른 표현**입니다.

팀원 문서의 `F114`, `F124a_all`은 발전소 예측 후보 번호입니다. 평가 기간인 `F2`, `F3`와 다릅니다. `W406`도 기상 입력 실험 번호이며 아래의 점수 W와 다릅니다. 서로 다른 기록 체계가 섞여 있으므로 문자 하나만으로 뜻을 판단하지 않습니다.

## 점수·학습 용어

| 용어 | 뜻 |
|---|---|
| W | 전력가격·시간대 가중치를 적용한 팀 예측 오차의 합. **낮을수록 좋음** |
| MAE | 예측과 실제 차이의 절댓값을 평균한 오차. 낮을수록 좋음. 가중 MAE는 항목별 중요도를 반영 |
| S | 대회 서버 점수. 높을수록 좋음. `S912`라는 제출 번호 자체가 점수는 아님 |
| 특징 / 입력 열 | 모델에 주는 정보. 예: 기온·구름·일사량·시간 |
| 기준선 | 개선 여부를 비교할 기준 모델·설정 |
| 혼합 / 앙상블 | 여러 모델의 예측을 정한 비율로 합치는 것 |
| OOF | 해당 평가 구간의 정답을 학습에 쓰지 않은 모델로 만든 예측. 시간순 검증에서는 과거로 학습해 뒤 기간을 예측 |
| 캐시 | 반복 계산을 줄이려고 저장한 입력·중간 결과 |
| 보정 | 예측이 지속적으로 높거나 낮은 경향을 과거 자료로 조정 |
| 직접 모델 | 발전소별 예측을 합치는 대신 팀의 총발전량을 바로 예측하는 모델 |
| 관측 마스크 | 점수 계산에 어떤 실제 관측값을 포함할지 표시한 기준 |
| p0-v1 | 초기 기간별 가중 MAE 평가 규칙의 버전. 연간 F2/F3 W 평가와 구분 |

W와 MAE는 단위·합산 방식이 다르고, 평가 기간·포함 관측도 다를 수 있습니다. 서로 다른 표의 숫자를 그대로 비교하지 않습니다. F2/F3는 이미 결과를 확인한 과거 평가로, 새 독립 최종 시험이 아닙니다.

## 기상자료 이름

GFS·GEFS는 미국 예보 계열, ICON은 독일 예보 모델, ECMWF ENS는 유럽중기예보센터의 앙상블 예보입니다. **TIGGE는 여러 기관 예보를 모은 자료 모음**이며 단일 모델 이름이 아닙니다. CAMS는 대기조성·에어로졸 등의 자료를 제공하는 서비스입니다. 예보 앙상블의 “31멤버”는 예보를 서로 다른 조건으로 계산한 31개 결과를 뜻합니다.

## 문장을 풀어 읽으면

> “G315에 ICON을 추가하고 F3 W를 비교한다.”

→ **팀원 실험 후보 G315의 설정에 독일 기상예보를 더해, 2024년 6월~2025년 5월의 팀 예측 오차가 줄어드는지 확인한다.**

현재 비교 기준은 G315지만, 팀원의 채택 버전은 S915, 11/6 확인된 서버 최고는 S912입니다. G315는 기록상 로컬 최저 후보였지만 추가 개선의 불확실성 때문에 팀원은 채택하지 않았습니다. [선택·제출 차이와 출처](experiments/parallel/2026-11-06-reflection-review.md).

정확한 F2/F3 시각 경계는 [연간 평가 계약](experiments/parallel/2026-11-04-ab-parallel.md#공통-평가-계약), P0~P5와 우리 실험 결과는 [실험 이력](../EXPERIMENTS.md)을 참고합니다. 앞으로 설명에는 **“2024~25년 평가(F3)”처럼 뜻을 먼저 쓰고 번호를 병기**합니다.
