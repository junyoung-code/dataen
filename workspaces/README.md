# A/B 작업 저장소

이 기기에서는 `a/`, `b/`, `control/`이 `../outputs/ab_20261104/` 아래의 실제 폴더를 가리킨다. 실행 환경과 고정 평가 경로를 보존하기 위해 실제 저장소는 이동하지 않았다. 링크는 Git에서 제외되며 원격 코드·가상환경·데이터를 복제하지 않는다.

- `a/`: A 전용 Git 저장소. 원격 맥미니 실행과 로컬 상태를 구분한다.
- `b/`: B 전용 Git 저장소. B1~B3 결과와 보고서는 여기서 확인한다.
- `control/`: 시작 시 공통 소스·평가 계약·실행 배정 기록.

새 clone에는 이 로컬 링크가 없다. 기존 실제 폴더가 있는 기기에서만 다음과 같이 연결한다.

```bash
ln -s ../outputs/ab_20261104/a workspaces/a
ln -s ../outputs/ab_20261104/b workspaces/b
ln -s ../outputs/ab_20261104/control workspaces/control
```

상위 저장소와 각 A/B 저장소의 Git 상태는 별개다. 이 링크를 통해 들어가도 해당 lane의 지침과 고정 평가 계약을 유지한다.
